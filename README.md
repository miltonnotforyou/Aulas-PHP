---

## 🎯 Objetivo

Centralizar o aprendizado da linguagem PHP, documentando a evolução desde a lógica básica de programação até a integração com bancos de dados relacionais (MySQL) e aplicação do padrão de Programação Orientada a Objetos (POO).

---

## 📚 Tópicos Abordados

* **Fundamentos do PHP:** Sintaxe básica, variáveis, constantes, tipos de dados e operadores.
* **Estruturas de Controle:** Condicionais (`if`, `else`, `elseif`, `switch`) e laços de repetição (`for`, `while`, `foreach`).
* **Vetores e Funções:** Manipulação de arrays (indexados e associativos) e criação de funções reutilizáveis.
* **Formulários e Superglobais:** Captura e validação de dados utilizando `$_GET`, `$_POST`, `$_REQUEST`, `$_SESSION` e `$_COOKIE`.
* **Programação Orientada a Objetos (POO):** Classes, objetos, atributos, métodos, encapsulamento e herança.
* **Banco de Dados (CRUD):** Conexão com MySQL via **PDO** / **MySQLi** e operações de Create, Read, Update e Delete.
